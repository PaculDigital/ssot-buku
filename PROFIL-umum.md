# PROFIL: Buku Umum

## Definisi

**[STANDAR]** Non-fiksi umum (hukum, ekonomi, bisnis, psikologi, manajemen,
dll) untuk pembaca umum/profesional: naratif-mengalir, akurat, bersumber.
BUKAN buku ajar (tanpa TIU/TIK/Latihan/Checklist).

## Input wajib

**[GATE]** Naskah, tema, atau outline + judul + penulis + target pembaca +
jumlah bab + ukuran/font + bahan. Form web WAJIB meminta bahan sebelum
produksi (P-09).

## Anatomi

**[STANDAR]** Cover (PNG HTML+CSS) → Hak Cipta/ISBN (kosong untuk penerbit)
→ Kata Pengantar DINAMIS (hook naratif, manfaat, target, harapan) → Daftar
Isi + Daftar Tabel + Daftar Diagram (dot leader + tab stop) → Daftar
Singkatan (OPSIONAL, bila banyak akronim) → BAB 1..N → Glosarium (OPSIONAL
— buku dagang standar cukup indeks) → Indeks → Daftar Pustaka → Tentang
Penulis (nama + gelar + afiliasi + riwayat + keahlian).

## Struktur bab

**[STANDAR]** Hook pembuka WAJIB kuat (kasus nyata / anekdot / data
mengejutkan / pertanyaan retoris — anekdot tunduk verifikasi sumber, lihat
Sitasi) → 4–6 sub-bab/bab → penutup bab paragraf naratif natural 2–4 kalimat
(BUKAN section Ringkasan formal) + transisi ke bab berikut.
**[GATE]** Paragraf 60–100 kata (standar readability). Kata/bab 3000–5000
(via chunking per sub-bab).

## Sitasi

**[STANDAR]** Endnotes / "Catatan & Sumber" bernomor per bab + Daftar Pustaka
di akhir. **[STANDAR]** Sitasi kurung APA in-text DILARANG untuk buku umum
(kebiasaan akademik yang mengganggu narasi; APA in-text hanya untuk jenis
akademik). Per-klaim (P-11): tiap klaim faktual ada sumbernya; angka per bab
hanya pedoman lunak. **[STANDAR]** Anekdot/kisah nyata WAJIB terverifikasi
sumbernya (boleh non-jurnal); tanpa sumber = label ilustrasi hipotetis.

## Visual

**[HOUSE]** Paket premium-konseptual (P-01): ilustrasi satu metafora cerdas,
palet navy/terracotta/krem, ruang negatif lapang, tekstur kertas; infografis
krem+navy, kotak radius 18px, label kotak; brief konseptual (bukan literal).
Diagram dipilih dari ISI (siklus/alur/piramida/dll). Label ditempel sesudah
gambar jadi. **[STANDAR]** Visual harus informatif; tabel Table Grid.

## Format

**[HOUSE]** B5 (17.6 × 25.0 cm) atau A5 alternatif; TNR 12pt (alternatif
Garamond 12pt); spasi 1.15 (alternatif 1.5); heading bab 16pt, sub-bab 14pt;
margin 2 cm; footer PAGE. Bab FLEKSIBEL 8–12 (spesifik = 8, general = 12).
**[HOUSE]** Target halaman = rentang + aturan "dilarang mengganjal" (buku
padat mengalahkan buku diganjal demi halaman).

## Gerbang

**[GATE]** Gerbang paket gaya: jenis yang dipilih tidak boleh jatuh ke gaya
lain tanpa ketahuan (gerbang terbukti bergigi: fallback senyap = GAGAL).
**[GATE]** QC narasi: hook kuat + terverifikasi, 0 ciri AI/kaku ("Penting
untuk dicatat", "Secara komprehensif", "Di era digital ini", "Dapat
disimpulkan bahwa"), 0 frasa repetitif lintas bab, 0 markdown, cross-bab
("Pada bab sebelumnya..." bab>1 + "Bab selanjutnya..." semua bab).
**[STANDAR]** Review: editor naskah + fact-checker sebelum final.
