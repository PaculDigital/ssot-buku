# PROFIL: Monograf

## Definisi

**[STANDAR]** Satu hasil penelitian spesifik dikupas sangat dalam menjadi
argumen ilmiah yang sustained. Bahan baku = naskah penelitian nyata (skripsi /
tesis / jurnal / laporan riset) — BUKAN tema bebas, BUKAN RPS.

## Input wajib

**[GATE]** Naskah penelitian (DOCX/PDF). Penulis + afiliasi diambil dari
metadata naskah atau input pemesan — **[STANDAR]** DILARANG default hardcode
nama penulis (nama default lama dihapus dari profil ini). Form web WAJIB
meminta unggah naskah sebelum produksi (P-09).

## Anatomi

**[STANDAR]** Cover → Hak Cipta/ISBN (diisi penerbit) → Kata Pengantar
(dinamis) → Daftar Isi + Daftar Tabel + Daftar Gambar → 8 BAB → Daftar
Pustaka (APA 7, hanging indent) → Glosarium (tabel 2 kolom) → Indeks →
Tentang Penulis.

## Struktur bab

**[STANDAR]** BAB 1 Pendahuluan (15–18 hlm): latar, masalah, pertanyaan +
tujuan, kontribusi + kebaruan, sistematika. BAB 2 Konteks Objek (15–18):
profil sektor/organisasi/komunitas, kondisi empiris, perkembangan isu.
BAB 3 Landasan Teoretis (20–24): teori utama, konsep kunci, hubungan
antarvariabel/konsep. BAB 4 Kajian Terdahulu + Kerangka (18–22): state of
the art, research gap, posisi penelitian, kerangka konseptual/proposisi.
BAB 5 Metodologi (15–18): pendekatan/desain, populasi/sampel/informan,
instrumen/pengumpulan, teknik analisis, validitas/reliabilitas/keabsahan.
BAB 6 Temuan (20–25): data + profil responden, hasil per pertanyaan riset,
tabel/diagram/kutipan informan, ringkasan temuan. BAB 7 Debat + Pembahasan
(25–35, BAB INTI) — DUA VARIAN **[HOUSE]**: (a) debat: 7.1 posisi temuan →
7.2 argumen Pro → 7.3 argumen Kontra → 7.4 sintesis (apa bertahan, apa
dimodifikasi, kondisi batas) → 7.5 novelty → 7.6 implikasi; (b) sintesis
interpretatif (riset deskriptif/kualitatif tanpa kontra tebal). BAB 8 Penutup
(10–15): kesimpulan, keterbatasan, rekomendasi, agenda lanjutan.
**[STANDAR]** Novelty 5 lapis (objek, konteks, hubungan konsep, metode,
temuan) — tiap klaim berstatus: Terbukti dari naskah / Didukung literatur /
Interpretasi masuk akal / Belum cukup bukti (→ tulis sebagai proposisi,
bukan fakta).
**[STANDAR]** Aturan ubah-skripsi-jadi-monograf: tulis ulang untuk pembaca;
BUANG aparat ujian (bahasa "tujuan penelitian", format sidang, halaman
pengesahan). Skripsi dicetak apa adanya = gagal standar.

## Sitasi

**[STANDAR]** OpenAlex per bab (topik + tahun ≥2020, kueri dibersihkan dari
nama author + tahun) + classic refs; search-then-lock (hanya kutip dari list
terverifikasi). **[GATE]** Verifikasi KETAT fail-closed (P-02): sitasi tak
terverifikasi ditolak — flag saja TIDAK cukup.

## Visual

**[STANDAR]** 8–10 tabel (hanya data asli penelitian atau sintesis literatur
bersumber); 4 diagram (kerangka konsep Bab 3, alur metode Bab 5, peta temuan
Bab 6, matriks debat Bab 7); 0 infografis; 0 ilustrasi AI dalam bab;
1 cover sederhana. **[GATE]** Distribusi ini yang berlaku — tuntutan lama
"≥1 diagram/bab (8 total)" DIHAPUS karena bertentangan dengan distribusi.

## Format

**[HOUSE]** A5 (14.8 × 21.0 cm), Cambria 11pt body / 14pt heading, margin
2 cm, spasi 1.15, footer PAGE, page break sebelum Daftar Pustaka +
Glosarium. PDF Turnitin = A4. Target 150–180 halaman (P-04); lantai kata
≥45.000 (target lama 25.000 kata DIHAPUS karena tidak menutup hitungan).

## Gerbang

**[GATE]** Ekstraksi naskah disetujui → outline disetujui (approver jalur:
operator = Boss, web = pelanggan) → produksi per sub-bab (Bab 7: call terpisah
Pro/Kontra/Sintesis/Novelty) → QC fail-closed: docx >100KB, 0 section
gagal/kosong, diagram terpasang sesuai distribusi, PDF Turnitin A4.
**[STANDAR]** Review pakar WAJIB: 1–2 reviewer sejawat sebelum final.
**[STANDAR]** Etik + anonimisasi WAJIB sebelum Bab 6: persetujuan etik,
anonimisasi nama/lokasi informan, izin kutip. **[STANDAR]** DILARANG mengarang
data penelitian (angka, responden, lokasi, hasil statistik di luar naskah).
