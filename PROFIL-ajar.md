# PROFIL: Buku Ajar OBE

## Definisi

**[STANDAR]** Buku ajar berbasis RPS OBE: isi disusun dari capaian
pembelajaran, aparat pedagogis lengkap, dan penilaian selaras dengan tujuan.
Dipakai bila: upload RPS, sebut CPL/CPMK/OBE, atau minta buku ajar/matkul.
BUKAN buku umum.

## Input wajib

**[GATE]** RPS (PDF/DOCX) ATAU naskah buku. Triase Phase 0 WAJIB PERTAMA
(sebelum mulai): (1) marker RPS (CPL/CPMK/Sub-CPMK/RPS/mata kuliah/SKS/
minggu ke; skor ≥4 = RPS) → Mode A; (2) struktur bab (BAB romawi) +
rasio pertanyaan body: ≥5% = workbook → Mode C rewrite total, <5% = narasi
→ Mode B enhance; (3) naskah tidak jelas (<30 paragraf, atau >70% bullet
pendek, atau tanpa struktur bab) → TOLAK + TANYA pemesan (jangan asumsi).
**[STANDAR]** Pelajaran kritis: enhance workbook = Frankenstein (narasi
penulis campur jawaban generik) — workbook WAJIB rewrite total, jangan patch.
Form web WAJIB meminta unggah RPS/naskah sebelum produksi (P-09).

## Anatomi

**[STANDAR]** Cover → Kata Pengantar/Pendahuluan DINAMIS (400–600 kata: hook
cerita, mengapa buku ini berbeda, manfaat konkret, target mahasiswa +
profesional, tutup "Penulis/nama/gelar/universitas" rata kanan) → Daftar Isi
+ Daftar Tabel + Daftar Diagram (dot leader + tab stop) → BAB 1..N →
Glosarium (tabel 2 kolom) → Indeks (istilah → bab) → Daftar Pustaka (APA 7)
→ Tentang Penulis (nama + gelar + universitas + riwayat S1/S2/S3 +
pekerjaan + keahlian).

## Struktur bab

**[STANDAR]** Tujuan dan Sasaran Pembelajaran → TIU (2–3 poin) → TIK
(5–7 poin kata kerja) → sub-bab (2–3 paragraf UTUH 60–100 kata; p1 konsep +
contoh, p2 analisis + aplikasi + sitasi, p3 opsional studi kasus) + VISUAL
MARKER → Ringkasan Bab (5–7 kalimat + kaitan bab berikut) → Latihan (5–7
soal + KUNCI JAWABAN + pembahasan, minimal di akhir buku) → Checklist
(`- [ ] <Kata Kerja> <objek>`; DILARANG awalan "Saya dapat/mampu/memahami";
gaya self-assessment pembaca) → Bacaan Lanjutan per bab (wajib vs anjuran).
**[STANDAR]** Pemetaan istilah (koreksi standar): TIU = level CPMK, TIK =
level Sub-CPMK. Buku ajar modern menulis CPMK/Sub-CPMK; TIU/TIK tanpa
pemetaan dibaca sebagai buku lama.
**[GATE]** Ambang paragraf (P-12): 60–100 kata (3–5 kalimat); <50 kata =
GAGAL (gabung dengan paragraf berikut); >100 kata = belah. Transisi MAKSIMAL
3 frasa/bab (>3 = GAGAL). Personal ≥25% (Anda, mahasiswa). 0 pertanyaan
"Jelaskan..." di body. Jangan kurangi narasi (output ≥ draft).

## Sitasi

**[STANDAR]** APA 7, per-klaim (P-11); angka 5+/bab hanya pedoman lunak,
bukan gate. Kueri dibersihkan dari nama author + tahun. **[GATE]** Verifikasi
KETAT fail-closed (P-02).

## Visual

**[STANDAR]** Tabel format wajib (kolom); diagram `[DIAGRAM N.1: Judul -
deskripsi]`; cover HTML+CSS; visual per sub-bab via VISUAL MARKER (tabel /
infografis / diagram / ilustrasi sesuai isi). Label ditempel sesudah gambar
jadi.

## Format

**[HOUSE]** B5 DEFAULT (lebih aman untuk visual) atau A5 HANYA bila dominan
teks minim visual; margin 2 cm; TNR 12pt body, 9pt italic TIU/TIK, 16pt heading
bab; spasi 1.15. Target narasi 1500–2000 kata/bab, 8–12 bab.

## Gerbang

**[GATE]** Outline disetujui (approver jalur: operator = Boss, web =
pelanggan) → produksi BCP chain per bab (ringkasan bab N = konteks bab N+1)
→ QC: 0 pertanyaan di body (Mode C), paragraf 60–100 kata, transisi ≤3/bab,
personal ≥25%, cross-bab ("Pada bab sebelumnya..." bab>1 + "Bab
selanjutnya..." semua bab). **[GATE]** Gerbang keselarasan: tiap TIK/Sub-CPMK
minimal 1 butir latihan yang mengujinya. **[STANDAR]** Review: dosen sejawat
+ uji keterbacaan mahasiswa sebelum final.
